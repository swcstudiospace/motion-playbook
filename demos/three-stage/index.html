05 · three.js

A 3D stage that never stalls the scroll.

The scene is built in an idle slot after the page paints. Shaders compile in the background, every program is warmed up once, and only then does the intro play.

Compile before you need it

renderer.compileAsync() plus one render with frustum culling off means no program is ever built mid-scroll. Watch the program count in the corner: it never changes once the scene is up.

Resolution that adapts

The renderer tracks average frame time. Slower than 22 ms and it drops the pixel ratio a step; faster than 12 ms and it climbs back, never more than once every 1.5 seconds.

Sleep when nobody's watching

The render loop only plays while this section is on screen, and the whole anime.js engine pauses six seconds after the last input. Stop scrolling and watch the engine row in the readout.
