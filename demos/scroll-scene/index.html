02 · Scroll scene

One timeline. Zero per-dot tweens.

140 squares move through six formations as you scroll. Switch between Tracks and Tweens at the top and compare the setup time in the corner.

Grid

The tweens version adds one animation per square per chapter: 700 of them here. The tracks version stores start and end positions and works out each square from the timeline's current time.

Wave

Both versions read timeline.currentTime, so scroll smoothing, seeking and reversing behave identically.

Spiral

Staggering is just a per-square offset on the segment's start time, so it costs nothing extra.

Burst

The render loop is an anime.js timer that only plays while this section is on screen, and the whole engine sleeps after six seconds without input.

Stack

On spectrumweb.co this change took the 3D scene's setup from roughly 780 ms of timeline building to under 120 ms.

End of the scene.
