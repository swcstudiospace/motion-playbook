01 · Reveals

Content that arrives as you read.

The title and this paragraph are visible before any JavaScript runs. Everything below is scrubbed by scroll: it fades in, holds while you read it, and leaves as it scrolls away.

Rule

Measure once, write every frame.

Each reveal reads its element height once at setup. During scroll, anime.js only writes opacity and transform, so the browser never has to recalculate layout mid-frame.

  • Heights read at setup and on resize
  • Opacity and transform during scroll
  • No getBoundingClientRect in the hot path

Rule

Words slide, they don't blur.

Splitting a heading into words gives you a lovely masked rise. Blurring each word as well creates one filter layer per word, and every one is repainted on every scroll frame. Keep the rise, drop the per-word blur.

Rule

Blur where it's cheap.

Blocks get a soft 8px blur on desktops with a fine pointer, and none on phones. Phones still get the fade and the rise, which is what the eye actually tracks.

Rule

Smooth the scrub.

A sync value of 0.45 lets each reveal glide toward the scroll position instead of snapping to it. With reduced motion turned on, everything is simply visible.

Fallback

Never stuck invisible.

Elements start hidden only when motion is on, and a CSS animation reveals them after 2.5 seconds if the JavaScript never arrives.
